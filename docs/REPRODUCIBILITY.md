# 재현 및 보관 범위

이 저장소는 DGX Spark에서 실행한 10종 바이오 AI 벤치마크의 보고서·실행 코드·환경/설정·측정 지표를 공유한다. 모든 원본 데이터와 가중치를 포함하는 실행 이미지가 아니다.

- 기본 실험과 입력 규모·배치 확대 후속은 서로 다른 run이다. 같은 모델이라도 추론/학습, 정밀도, 길이 정책, 측정 구간을 먼저 확인한다.
- 코드에는 실제 실행 당시의 `/home/hyein/ai-benchmark`, `/work`, `/workspace`, `/cache` 경로가 남아 있다. 다른 시스템에서는 작업 루트와 Docker bind mount를 조정해야 한다.
- ARM64 DGX Spark 환경을 기준으로 했다. 모델별 설치/다운로드/입력 검사 스크립트와 기록된 패키지 버전·가중치 리비전·해시를 확인한다. CPU/GPU나 라이브러리 버전이 다르면 같은 수치를 보장하지 않는다.
- 모델별 데이터 `sources`/`manifest`/`audit` JSON은 실제 출처·해시·입력 검사 기록이다. 원본 데이터를 다시 확보한 뒤 해시와 입력 구조를 대조한다. 원본 데이터·모델의 라이선스 및 인용 조건은 각 출처를 따른다.
- `results/<run_id>`에는 공유할 수 있는 작은 JSON/CSV/TSV 설정·지표·자원 시계열을 선별했다. 원본 이미지·발현 행렬·서열 전체·토큰 배열·학습 가중치·대형 예측 배열·컨테이너·가상환경·캐시는 로컬 보관이다.
- 스크립트와 기록은 실제 실행 및 오류 복구 이력이다. 모든 과거 launch 스크립트를 한꺼번에 실행하면 안 된다. 실행 목적과 run/출력 경로를 확인하고 GPU 작업은 하나씩 수행한다.
- 상대 링크가 가리키는 원본이 공유 범위 밖이면 보고서에 `로컬 보관`으로 표시했다. 원래 기록한 절대 경로와 원본 artifact 설명은 보존한다.

모델별 방법과 완료/미수행 범위는 해당 보고서를 우선한다. 결과는 단일 장비의 특정 조건에서 관측한 값이며 임상적 성능이나 모델의 절대 최대 배치를 입증하지 않는다.
